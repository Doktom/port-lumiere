# Port-Lumière

Petit jeu de ferme en 3D cel-shading, inspiré de Stardew Valley. Cultive ton champ, pêche à la rivière ou au port, vends tes récoltes au village.

Jouable directement dans le navigateur (Three.js, un seul fichier `index.html`).

## Commandes

- ZQSD / flèches : marcher (Maj pour courir)
- Espace ou clic : utiliser l'outil
- E ou clic droit : parler, acheter, dormir, récolter
- 1 à 0 / molette : choisir un objet
- F : manger la récolte sélectionnée
- H : aide
